# 샤들링 (Shardlings)

샤들링을 모으고 합성하는 실시간 자동 사냥 RPG. 안드로이드 출시를 목표로 만드는 중입니다.

현재 상태: 시제품. 그림 일부와 숫자는 임시이고, 저장 기능은 아직 없습니다.

## 실행

빌드 없이 돌아갑니다. 이 폴더에서 정적 서버를 띄운 뒤 브라우저로 여세요.

```bash
npx serve .
```

## 파일

| 경로 | 내용 |
|---|---|
| `index.html` | 게임 전체 (시제품 단계라 한 파일) |
| `art/` | 필드용 그림 (세로 32칸) |
| `art/big/` | 정보 화면용 큰 그림 |
